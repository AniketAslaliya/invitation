# Prutha & Jatin — Wedding Invitation

React + Vite + TypeScript. Three.js 2.5D parallax (following `.claude/skills/threejs-parallax`) on desktop, and lightweight layered images on phones.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview
```

## Things to fill in later (no component changes needed)

All in `src/data/siteConfig.ts`:

- **Venue**: set `venue.name`, `venue.addressLines` and, optionally, `venue.mapsUrl` (a Google Maps share link). Until one of them is set, the Location chapter shows "Venue details will be shared soon". When only a name or address is set, "Get Directions" opens a Google Maps search for it.
- **Music**: put an audio file you have the rights to use in `public/` (e.g. `public/music/shehnai.mp3`) and set `music.src: '/music/shehnai.mp3'`. The play/pause control appears automatically. It never autoplays.

Event dates, times and titles live only in `src/data/weddingEvents.ts`. Weekdays, the countdown and all labels are derived from it, always in Asia/Kolkata time.

## Artwork

The originals in `Groom/` are never modified. Derivatives in `public/media/` are generated by:

```bash
npm run assets                     # Python: plates, branch/petal cutouts, envelope sprites, story layers
node scripts/build-ornaments.mjs   # SVG lanterns, arcades, garlands, drapes, diyas, frames
```

## Rendering modes

- Desktop (fine pointer + WebGL): Three.js layered scenes with mouse and scroll parallax, plus Lenis smooth scrolling.
- Phones and tablets: the same layers as transformed images. Three.js is never downloaded.
- `prefers-reduced-motion`: static composed layers with no continuous motion.
- WebGL unavailable or lost: automatic fallback to the image layers.

For testing, you can force a mode with `?render=webgl`, `?render=dom` or `?render=static`.
