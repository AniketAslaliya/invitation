# Prutha & Jatin — Wedding Invitation

A mobile-first wedding invitation: React + Vite + TypeScript, layered 2.5D scroll parallax (following `.claude/skills/threejs-parallax`), GSAP ScrollTrigger section blends and Framer Motion reveals.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview
```

## Deploy on Vercel

1. Import the GitHub repo in Vercel (framework is detected as **Vite**; settings come from `vercel.json`).
2. Build command `npm run build`, output `dist` — nothing else to configure, no environment variables.
3. Every push to `master` redeploys.

## Things to fill in later (no component changes needed)

All in `src/data/siteConfig.ts`:

- **Venue**: Lion Valley Resort, Malanka, Junagadh. Directions, Apple Maps, the map preview and copy-address are all built from `venue.name` + `venue.addressLines`. Paste an exact Google Maps share link into `venue.mapsUrl` to pin it precisely.
- **Music**: put an audio file you have the rights to use in `public/` (e.g. `public/music/shehnai.mp3`) and set `music.src: '/music/shehnai.mp3'`. The play/pause control appears automatically. It never autoplays.

Event dates, times and titles live only in `src/data/weddingEvents.ts`. Weekdays, the countdown and all labels are derived from it, always in Asia/Kolkata time.

## Artwork

The originals live in a local `Groom/` folder that is **not** committed (see `.gitignore`); they are never modified. Derivatives in `public/media/` are generated by:

```bash
npm run assets                     # Python: plates, branch/petal cutouts, envelope sprites, story layers
node scripts/build-ornaments.mjs   # SVG lanterns, arcades, garlands, drapes, diyas, frames
```

## Rendering

- Every device gets the phone layout (a centred column on large screens) with scroll-driven parallax only.
- `prefers-reduced-motion`: static composed layers, no continuous motion.
- The Three.js renderer remains available for experiments via `?render=webgl`; it is never downloaded otherwise.
